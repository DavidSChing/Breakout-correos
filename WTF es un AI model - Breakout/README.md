## Design

Uses `Open World - Breakout x Lead PUCP - AXIS/Open_World-v2.0.html` as the
existing event-template reference. Uses Breakout blue (#2430ff) across the
header and registration button, with white and pale-blue header text. Keeps
the Luma cover's large title and AI TALK EDITION label. Uses a
clearer reading order, one primary registration button, and a separate
practical-details block. Copy reflects the informal, beginner-friendly talk.

All visual elements are live HTML: no image hosting, tracking pixels, web fonts,
or generated assets are required. Presentation tables and inline styles keep
the layout usable when email clients remove embedded CSS. An Outlook width
fallback caps the email at 600px. Actual inbox rendering can vary; browser
previews do not replace a test send.

Validated in Chromium at 900px, 375px, and 320px viewport widths with no
horizontal overflow. Checked balanced HTML, presentation-table roles, and
the registration button destination. No actual emails were sent.

The repository's existing gallery discovers HTML files automatically after
they are published, so no gallery changes are needed.
